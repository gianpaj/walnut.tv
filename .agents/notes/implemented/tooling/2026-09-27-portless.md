# Portless development URL

## Decision

`pnpm dev` uses the project dependency `portless@0.15.6` with the name `walnut`,
`.localhost`, and LAN mode disabled. Next binds to `127.0.0.1`.
Use the printed URL: saved proxy settings can add a port.
`pnpm dev:direct` runs Next without the proxy.

The user preferred `.local` with `.localhost` as a fallback. Choose `.localhost`
because Portless recommends avoiding `.local` outside its Bonjour/mDNS LAN mode.
Do not enable LAN sharing or install an OS startup service for this workflow.
Different origins have separate watched-history storage.

## Verification

- Isolated HTTPS proxy on port 1443, temporary certificate, hosts sync disabled.
  `pnpm dev` registered `walnut.localhost` and served the app through the proxy.
- HTTP checks: homepage 307 to Hustle, retired video 308 home, unknown category 404.
- `agent-browser` reached `/hustle`, loaded 32 Next assets, and reported a secure
  context. The browser ignored the self-signed test certificate; system CA trust
  was not changed. The feed showed the existing empty/quota message, not playback.
- Format check, TypeScript 7 typecheck, Oxlint, and 18 tests passed.
- Test app, proxy, and browser stopped. Shared `.dev`/1355 proxy state was unchanged.
